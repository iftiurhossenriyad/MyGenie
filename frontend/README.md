# MyGenie Frontend

**An Intelligent AI-Powered Personal and Business Assistant**

The React + TypeScript frontend for MyGenie — a Bangla-first, bilingual AI assistant for small businesses.

---

## 🎯 Features

### Authentication
- ✅ Login + Register pages
- ✅ JWT token management
- ✅ Protected routes
- ✅ Auto-refresh user session

### Personal Mode
- ✅ Dashboard with quick stats
- ✅ **Tasks** — Create, complete, delete
- ✅ **Notes** — Create, search (full-text), delete
- ✅ **Appointments** — Create, cancel, delete with date/time picker
- ✅ **AI Chat** — Chat with grounded AI responses + human handoff

### Business Mode
- ✅ **Dashboard** — Stats + Quick actions
- ✅ **Profile** — Business info (hours, policies, delivery)
- ✅ **Products** — CRUD + stock adjustments
- ✅ **Orders** — List + status workflow
- ✅ **Bookings** — Services + Bookings management
- ✅ **FAQs** — Bilingual (Bangla + English)

### Design
- ✅ **Navy + Gold** color scheme (matching pitch deck)
- ✅ **Bilingual UI** — Bangla + English labels
- ✅ **Responsive** — Desktop + Mobile
- ✅ **Mode Switcher** — Switch between Personal and Business workspaces
- ✅ **Accessible** — Readable errors, clear navigation

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | React 18 |
| **Language** | TypeScript |
| **Build Tool** | Vite 8 |
| **Styling** | TailwindCSS 3 |
| **Routing** | React Router v6 |
| **HTTP Client** | Axios |
| **State** | React Context API |
| **Icons** | Emoji + Text |

---

## 📋 Prerequisites

Before running this project, ensure you have:

- **Node.js** 18+ ([Download](https://nodejs.org/))
- **npm** 9+ (comes with Node.js)
- **Backend API** running on `http://127.0.0.1:8000`
